# Rompeto · Cozinha & Vinho

Site do Rompeto, restaurante e adega em Mont'Serrat, Porto Alegre. Astro, saída estática.

```bash
npm install
npm run dev     # http://localhost:4321
npm run build   # gera dist/
```

- Horários, WhatsApp, endereço e destaques dos cardápios: `src/data/site.ts`.
- Cardápios completos em PDF: `public/cardapios/` (trocar a cada estação).
- Fotos reais (Fábio Mattos), texturas, ilustrações e logos da marca: `public/img/`, `public/brand/`.
- Fontes da marca: `public/fonts/` (Affogato, Oliver Quin) e EB Garamond via `@fontsource`.

Identidade: Manual de Identidade Visual Rompeto v1.0. Imagens de pratos ou ambientes geradas por IA são proibidas.
